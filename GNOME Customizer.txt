CODEX MASTER BUILD BRIEF
========================

PROJECT NAME
------------
Working name: GNOME Customizer

PURPOSE
-------
Build a complete, polished, native customization application for modern GNOME that unifies:

1. GNOME desktop appearance customization
2. GNOME Shell appearance and selected shell-behavior functions needed to provide an integrated dock/blur/panel experience
3. GDM login-screen customization
4. A safe visual Theme Builder
5. Import/export/shareable appearance-only themes
6. Diagnostics, status, safe apply, safe rollback, and safe restore

This is not a mockup project.
This is not a shell-script wrapper.
This is not a clone of GNOME Tweaks.
This is not a fork of GDM Settings.
This is not a bundle of third-party extensions.

The goal is a complete production-quality application.

The application should feel like something the GNOME team could have shipped, but with the visual restraint, consistency, spacing, polish, preview quality, and attention to detail associated with excellent Apple software.

Do not copy macOS.
Do not reproduce Apple controls, traffic-light window buttons, Apple fonts, Apple icons, or proprietary visual assets.

The visual direction is:

"Native GNOME 50 design with Apple-level polish."

It must not look like:
- a generic web dashboard
- a gamer utility
- a purple neon control panel
- a cheap preferences dialog
- an old GTK3 application
- a Windows utility
- a fake macOS application

============================================================
PRODUCT PHILOSOPHY
============================================================

GNOME Customizer should be a unified, polished customization product.

It should solve the current fragmentation problem where users need:
- GNOME Settings
- GNOME Tweaks
- multiple GNOME Shell extensions
- command-line GSettings
- manual CSS
- manual GDM resource editing

The user should instead have one coherent application.

The app should clearly separate three technical domains:

DESKTOP SETTINGS
- normal logged-in user's settings
- use supported GSettings / desktop APIs
- normally no administrator authentication

SHELL CUSTOMIZATION
- appearance and shell-level functions that cannot be implemented with ordinary GSettings
- handled by one GNOME Customizer companion GNOME Shell component
- this component belongs to this project
- do not bundle Dash to Dock
- do not bundle Blur My Shell
- do not require those extensions
- reproduce only the desired functions in our own focused implementation

GDM LOGIN SCREEN
- system-level login-screen settings
- use GDM dconf and carefully generated GResource changes
- use a minimal PolicyKit-protected helper
- GUI must never run as root

============================================================
STAGED CHANGE MODEL
============================================================

Do not immediately apply every potentially destructive or privileged change.

Use a staged model.

The user can change multiple values and see them in the preview.

Show:
- pending changes count
- Apply
- Discard

Desktop-only changes that are safe and reversible may optionally support live preview, but there must still be a clear distinction between previewed and committed state where necessary.

GDM changes must be staged.

On Apply:
1. Validate all values.
2. Validate all selected assets.
3. Prepare generated files.
4. Validate generated resource structures.
5. Request PolicyKit authorization once if privileged work is required.
6. Apply the transaction.
7. Verify success.
8. Roll back where feasible if a critical stage fails.
9. Show a subtle success toast.

Do not show a password box inside the app.

============================================================
PRIVILEGE / SECURITY ARCHITECTURE
============================================================

THE GUI MUST NEVER RUN AS ROOT.

Never require:
sudo gnome-customizer

Never run the GTK process through pkexec.

Use:

GTK4 / Libadwaita GUI
      |
      | Gio / GDBus
      v
PolicyKit protected helper
      |
      v
narrow root-only system operations

The helper must expose explicit methods such as:

- ApplyGdmDconf
- InstallGdmResource
- ActivateGdmResource
- RestoreGdmResource
- InstallGdmAssets
- ApplyMonitorConfiguration
- RestoreMonitorConfiguration
- RestoreGdmDefaults
- QueryPrivilegedStatus if genuinely necessary

DO NOT expose:
- ExecuteCommand
- RunShell
- arbitrary paths
- arbitrary scripts
- arbitrary environment injection

Validate all paths and values.

Use fixed allowed locations.

Avoid shell=True.

Use argv arrays for subprocesses.

Do not accept user-provided command lines.

POLKIT
------
Install an action such as:

io.github.gnomecustomizer.modify-system

Description:
Authentication is required to modify the GNOME login screen.

Use the normal Ubuntu PolicyKit authentication agent.

The intended UX:
- user opens app normally
- makes several changes
- presses Apply
- normal Ubuntu authentication dialog appears once
- user authenticates
- helper performs the allowed changes

============================================================
OWNED FILES AND SYSTEM SAFETY
============================================================

Use application-owned configuration.

GDM dconf override:

/etc/dconf/db/gdm.d/99-gdm-customizer

Do not overwrite unrelated files such as:

/etc/dconf/db/gdm.d/95-gdm-settings

Do not delete unrelated files in:
/etc/dconf/db/gdm.d/

Ensure:
/etc/dconf/db/gdm.d

exists when required.

GDM dconf profile:
 /etc/dconf/profile/gdm

If it does not exist, create the minimal correct profile.

A known working profile on Ubuntu is:

user-db:user
system-db:gdm
file-db:/usr/share/gdm/greeter-dconf-defaults

Do not overwrite a valid existing profile unnecessarily.

After changing GDM system dconf:
dconf update

Check return status.

============================================================
KNOWN VERIFIED TARGET DETAILS
============================================================

A target Ubuntu 26.04 system used during development reported:

gdm:x:120:121:Gnome Display Manager:/var/lib/gdm3:/bin/false

GDM 50.1
GNOME Shell 50.1

Do not assume the GDM account name is always the same.

Detect:
1. gdm
2. Debian-gdm
3. fail gracefully if neither is available

For querying GDM settings, use the correct GDM profile.

Example known-working concept:

machinectl shell gdm@ /usr/bin/env \
DCONF_PROFILE=gdm \
gsettings get org.gnome.desktop.interface clock-format

Do not confuse the regular user dconf database with the GDM profile.

============================================================
GDM GRESOURCE ARCHITECTURE
============================================================

On the verified Ubuntu 26.04 target:

/usr/share/gnome-shell/gdm-theme.gresource

is managed through update-alternatives.

Known alternatives included:

/usr/share/gnome-shell/gnome-shell-theme.gresource

and:

/usr/share/gnome-shell/theme/Yaru/gnome-shell-theme.gresource

The customizer must never blindly overwrite stock package-managed resources.

Create an app-owned resource, for example:

/usr/local/share/gnome-customizer/gnome-shell-theme.gresource

Register/select it through update-alternatives.

Before activation:
- record the previous alternative
- verify the custom resource exists
- verify gresource list succeeds
- verify required resource paths exist

On restore/uninstall:
- restore previous valid alternative if available
- otherwise restore a valid stock Ubuntu/Yaru resource
- never leave update-alternatives pointing to a deleted file

============================================================
GRESOURCE BUILD PIPELINE
============================================================

Use:
- gresource
- glib-compile-resources

Known GNOME 50 resource namespace:

/org/gnome/shell/theme/

Known files may include:
- gdm.css
- gnome-shell-dark.css
- gnome-shell-light.css
- gnome-shell-high-contrast.css
- other shell assets

Safe workflow:
1. Identify stock source resource.
2. Extract it to a temporary workspace.
3. Preserve the original tree.
4. Add only intended custom assets.
5. Generate the resource XML.
6. Generate/append only our controlled CSS.
7. Compile new GResource.
8. Validate with gresource list.
9. Validate expected CSS/resource paths.
10. Only after successful validation install the resource.
11. Only after installation activate with update-alternatives.

Never activate partially generated resources.

============================================================
THEME SYSTEM: CORE RULE
============================================================

Themes are APPEARANCE ONLY.

A theme MUST NOT be able to:
- execute commands
- contain executable scripts
- contain Python
- contain JavaScript
- contain shell code
- install extensions
- enable arbitrary extensions
- change power behavior
- change keyboard shortcuts
- change login security policy
- change user list behavior
- add GNOME features
- add dock functionality that isn't already built into GNOME Customizer
- modify services
- modify system packages
- write arbitrary files
- run post-install hooks
- inject arbitrary raw Shell CSS in the standard theme format

Themes only describe visual values and assets.

The application owns the translation from theme properties to GNOME 50 implementation.

This is critical for safety, compatibility, and supportability.

============================================================
THEME FILE FORMAT
============================================================

Define an open, documented, versioned package format.

Recommended extension:

.gctheme

A .gctheme may be a ZIP-compatible archive with a controlled internal structure.

Example:

AuroraPurple.gctheme
  manifest.json
  assets/
    desktop-wallpaper.webp
    login-wallpaper.webp
    preview.webp
    optional-pattern.webp

Do not require a shell.css file in standard themes.

The application generates CSS from allowed manifest values.

Example manifest concepts:

{
  "format_version": 1,
  "name": "Aurora Purple",
  "author": "Eric",
  "description": "Dark purple and blue GNOME appearance.",
  "minimum_gnome": "50.1",
  "maximum_tested_gnome": "50.x",

  "desktop": {
    "color_scheme": "dark",
    "accent": "purple",
    "wallpaper": "assets/desktop-wallpaper.webp",
    "icons": "Yaru-blue",
    "cursor": "Yaru"
  },

  "shell": {
    "panel": {
      "background_type": "gradient",
      "color1": "#171126",
      "color2": "#3A1C71",
      "gradient_angle": 90,
      "opacity": 0.82,
      "blur": 20,
      "text_color": "#FFFFFF"
    },
    "menus": {
      "surface_color": "#121218",
      "opacity": 0.92,
      "blur": 18,
      "corner_radius": 14
    },
    "dock": {
      "background_color": "#15131C",
      "opacity": 0.75,
      "blur": 24,
      "corner_radius": 18
    }
  },

  "login": {
    "wallpaper": "assets/login-wallpaper.webp",
    "accent": "purple"
  }
}

The exact schema should be designed carefully and documented.

Use JSON Schema if practical.

Reject unknown dangerous fields.

Support forward-compatible optional fields carefully.

#!/usr/bin/env bash
set -Eeuo pipefail

# GDM Customizer
# Target: Ubuntu 26.04 / GNOME 50 / GDM 50
#
# Terminal-based GDM customization utility.
# It keeps its own dconf override file and its own custom GResource alternative.
# It does NOT remove or overwrite unrelated /etc/dconf/db/gdm.d/*. files.

APP_NAME="gdm-customizer"
APP_DIR="/usr/local/share/${APP_NAME}"
STATE_DIR="${APP_DIR}/state"

CUSTOM_RESOURCE="${APP_DIR}/gnome-shell-theme.gresource"
PREVIOUS_THEME="${APP_DIR}/previous-theme"
PREVIOUS_MONITORS="${APP_DIR}/monitors.xml.previous"
MONITORS_MARKER="${APP_DIR}/monitors-created"

GDM_LINK="/usr/share/gnome-shell/gdm-theme.gresource"
ALT_NAME="gdm-theme.gresource"
YARU_RESOURCE="/usr/share/gnome-shell/theme/Yaru/gnome-shell-theme.gresource"
SHELL_RESOURCE="/usr/share/gnome-shell/gnome-shell-theme.gresource"

DCONF_DIR="/etc/dconf/db/gdm.d"
DCONF_FILE="${DCONF_DIR}/99-gdm-customizer"
DCONF_PROFILE="/etc/dconf/profile/gdm"

# ------------------------------------------------------------
# Generic helpers
# ------------------------------------------------------------

die() {
    printf '\nERROR: %s\n\n' "$*" >&2
    exit 1
}

info() {
    printf '\n==> %s\n' "$*"
}

pause() {
    echo
    read -r -p "Press Enter to continue..." _
}

require_root() {
    if [[ ${EUID} -ne 0 ]]; then
        echo
        echo "Run this program with:"
        echo
        echo "  sudo $0"
        echo
        exit 1
    fi
}

check_commands() {
    local commands=(
        gresource glib-compile-resources update-alternatives dconf gsettings
        machinectl install mktemp readlink file find sed grep getent awk
        sort cp rm mkdir
    )
    local missing=()
    local cmd

    for cmd in "${commands[@]}"; do
        command -v "$cmd" >/dev/null 2>&1 || missing+=("$cmd")
    done

    if (( ${#missing[@]} > 0 )); then
        echo
        echo "Missing required commands:"
        printf '  %s\n' "${missing[@]}"
        echo
        echo "Install the main dependencies with:"
        echo
        echo "  sudo apt install libglib2.0-bin libglib2.0-dev-bin dconf-cli systemd-container"
        echo
        exit 1
    fi
}

ensure_dirs() {
    install -d -m 0755 "$APP_DIR" "$STATE_DIR"
}

ensure_gdm_dconf() {
    install -d -m 0755 "$DCONF_DIR"
    install -d -m 0755 /etc/dconf/profile

    if [[ ! -f "$DCONF_PROFILE" ]]; then
        cat > "$DCONF_PROFILE" <<'EOF'
user-db:user
system-db:gdm
file-db:/usr/share/gdm/greeter-dconf-defaults
EOF
        chmod 0644 "$DCONF_PROFILE"
    fi
}

calling_user() {
    if [[ -n "${SUDO_USER:-}" && "${SUDO_USER}" != "root" ]]; then
        printf '%s\n' "$SUDO_USER"
    else
        id -un
    fi
}

calling_user_home() {
    local user
    user="$(calling_user)"
    getent passwd "$user" | cut -d: -f6
}

normalize_path() {
    local path="$1"
    local home
    home="$(calling_user_home)"

    case "$path" in
        "~") path="$home" ;;
        "~/"*) path="${home}/${path#~/}" ;;
    esac

    readlink -f "$path" 2>/dev/null || true
}

validate_image() {
    local image="$1"
    [[ -n "$image" ]] || return 1
    [[ -f "$image" ]] || return 1
    [[ -r "$image" ]] || return 1

    case "$(file --brief --mime-type "$image")" in
        image/jpeg|image/png|image/webp) return 0 ;;
        *) return 1 ;;
    esac
}

image_extension() {
    case "$(file --brief --mime-type "$1")" in
        image/jpeg) echo jpg ;;
        image/png) echo png ;;
        image/webp) echo webp ;;
        *) return 1 ;;
    esac
}

valid_hex_color() {
    [[ "$1" =~ ^#[0-9A-Fa-f]{6}([0-9A-Fa-f]{2})?$ ]]
}

valid_number() {
    [[ "$1" =~ ^-?[0-9]+([.][0-9]+)?$ ]]
}

valid_integer() {
    [[ "$1" =~ ^[0-9]+$ ]]
}

state_path() {
    printf '%s/%s\n' "$STATE_DIR" "$1"
}

state_has() {
    [[ -f "$(state_path "$1")" ]]
}

state_get() {
    local p
    p="$(state_path "$1")"
    [[ -f "$p" ]] && cat "$p"
}

state_get_or() {
    local key="$1"
    local fallback="$2"
    if state_has "$key"; then
        state_get "$key"
    else
        printf '%s\n' "$fallback"
    fi
}

state_set() {
    ensure_dirs
    printf '%s\n' "$2" > "$(state_path "$1")"
    chmod 0644 "$(state_path "$1")"
}

state_unset() {
    rm -f "$(state_path "$1")"
}

dconf_string() {
    local s="$1"
    s="${s//\\/\\\\}"
    s="${s//\'/\\\'}"
    printf "'%s'" "$s"
}

ask_back_path() {
    local title="$1"
    local kind="${2:-file}"
    local input resolved

    while true; do
        clear
        echo "========================================"
        printf "          %s\n" "$title"
        echo "========================================"
        echo
        echo "Enter the full path."
        echo
        echo "Examples:"
        echo "  /home/$(calling_user)/Pictures/image.jpg"
        echo "  ~/Pictures/image.png"
        echo
        echo "B) Back"
        echo
        read -r -e -p "Path: " input

        case "$input" in
            b|B|back|BACK)
                return 1
                ;;
        esac

        resolved="$(normalize_path "$input")"

        if [[ "$kind" == "image" ]]; then
            if validate_image "$resolved"; then
                printf '%s\n' "$resolved"
                return 0
            fi
            echo
            echo "That is not a readable JPEG, PNG or WebP image."
        elif [[ "$kind" == "dir" ]]; then
            if [[ -d "$resolved" ]]; then
                printf '%s\n' "$resolved"
                return 0
            fi
            echo
            echo "That directory does not exist."
        else
            if [[ -f "$resolved" ]]; then
                printf '%s\n' "$resolved"
                return 0
            fi
            echo
            echo "That file does not exist."
        fi

        sleep 2
    done
}

ask_hex_color() {
    local title="$1"
    local input

    while true; do
        clear
        echo "========================================"
        printf "          %s\n" "$title"
        echo "========================================"
        echo
        echo "Enter a CSS hex color such as:"
        echo "  #000000"
        echo "  #3584e4"
        echo "  #ff7800"
        echo
        echo "B) Back"
        echo
        read -r -p "Color: " input

        case "$input" in
            b|B|back|BACK) return 1 ;;
        esac

        if valid_hex_color "$input"; then
            printf '%s\n' "$input"
            return 0
        fi

        echo
        echo "Invalid color. Use #RRGGBB or #RRGGBBAA."
        sleep 2
    done
}

ask_text() {
    local title="$1"
    local input

    clear
    echo "========================================"
    printf "          %s\n" "$title"
    echo "========================================"
    echo
    echo "B) Back"
    echo
    read -r -p "Value: " input

    case "$input" in
        b|B|back|BACK) return 1 ;;
    esac

    printf '%s\n' "$input"
}

ask_number_range() {
    local title="$1"
    local min="$2"
    local max="$3"
    local input

    while true; do
        clear
        echo "========================================"
        printf "          %s\n" "$title"
        echo "========================================"
        echo
        echo "Allowed range: $min to $max"
        echo
        echo "B) Back"
        echo
        read -r -p "Value: " input

        case "$input" in
            b|B|back|BACK) return 1 ;;
        esac

        if valid_number "$input" && awk -v x="$input" -v a="$min" -v b="$max" 'BEGIN { exit !(x>=a && x<=b) }'; then
            printf '%s\n' "$input"
            return 0
        fi

        echo
        echo "Invalid value."
        sleep 2
    done
}

ask_integer_range() {
    local title="$1"
    local min="$2"
    local max="$3"
    local input

    while true; do
        clear
        echo "========================================"
        printf "          %s\n" "$title"
        echo "========================================"
        echo
        echo "Allowed range: $min to $max"
        echo
        echo "B) Back"
        echo
        read -r -p "Value: " input

        case "$input" in
            b|B|back|BACK) return 1 ;;
        esac

        if valid_integer "$input" && (( input >= min && input <= max )); then
            printf '%s\n' "$input"
            return 0
        fi

        echo
        echo "Invalid value."
        sleep 2
    done
}

toggle_menu() {
    local title="$1"
    local key="$2"
    local apply_kind="${3:-dconf}"

    while true; do
        clear
        echo "========================================"
        printf "          %s\n" "$title"
        echo "========================================"
        echo
        echo "Current override: $(state_get_or "$key" "Ubuntu default")"
        echo
        echo "1) On"
        echo "2) Off"
        echo "3) Use Ubuntu Default"
        echo "B) Back"
        echo
        read -r -p "Choose: " choice

        case "$choice" in
            1) state_set "$key" true ;;
            2) state_set "$key" false ;;
            3) state_unset "$key" ;;
            b|B) return ;;
            *) continue ;;
        esac

        if [[ "$apply_kind" == "resource" ]]; then
            apply_resource_state
        else
            rebuild_dconf
        fi
        echo
        echo "Updated."
        pause
    done
}

gdm_get() {
    local schema="$1"
    local key="$2"

    machinectl shell "${GDM_USER}@" /usr/bin/env \
        DCONF_PROFILE=gdm \
        gsettings get "$schema" "$key" 2>/dev/null |
        grep -v '^Connected to ' |
        grep -v '^Connection to ' |
        tail -n1 || true
}

rebuild_dconf() {
    ensure_dirs
    ensure_gdm_dconf

    local tmp
    tmp="$(mktemp)"
    : > "$tmp"

    # org.gnome.desktop.interface
    if state_has accent_color || state_has color_scheme || state_has cursor_theme ||
       state_has cursor_size || state_has icon_theme || state_has show_battery ||
       state_has clock_date || state_has clock_seconds || state_has clock_weekday ||
       state_has clock_format || state_has font_name || state_has font_antialias ||
       state_has font_hinting || state_has text_scale; then

        echo "[org/gnome/desktop/interface]" >> "$tmp"
        state_has accent_color   && printf "accent-color=%s\n" "$(dconf_string "$(state_get accent_color)")" >> "$tmp"
        state_has color_scheme   && printf "color-scheme=%s\n" "$(dconf_string "$(state_get color_scheme)")" >> "$tmp"
        state_has cursor_theme   && printf "cursor-theme=%s\n" "$(dconf_string "$(state_get cursor_theme)")" >> "$tmp"
        state_has cursor_size    && printf "cursor-size=%s\n" "$(state_get cursor_size)" >> "$tmp"
        state_has icon_theme     && printf "icon-theme=%s\n" "$(dconf_string "$(state_get icon_theme)")" >> "$tmp"
        state_has show_battery   && printf "show-battery-percentage=%s\n" "$(state_get show_battery)" >> "$tmp"
        state_has clock_date     && printf "clock-show-date=%s\n" "$(state_get clock_date)" >> "$tmp"
        state_has clock_seconds  && printf "clock-show-seconds=%s\n" "$(state_get clock_seconds)" >> "$tmp"
        state_has clock_weekday  && printf "clock-show-weekday=%s\n" "$(state_get clock_weekday)" >> "$tmp"
        state_has clock_format   && printf "clock-format=%s\n" "$(dconf_string "$(state_get clock_format)")" >> "$tmp"
        state_has font_name      && printf "font-name=%s\n" "$(dconf_string "$(state_get font_name)")" >> "$tmp"
        state_has font_antialias && printf "font-antialiasing=%s\n" "$(dconf_string "$(state_get font_antialias)")" >> "$tmp"
        state_has font_hinting   && printf "font-hinting=%s\n" "$(dconf_string "$(state_get font_hinting)")" >> "$tmp"
        state_has text_scale     && printf "text-scaling-factor=%s\n" "$(state_get text_scale)" >> "$tmp"
        echo >> "$tmp"
    fi

    # Accessibility
    if state_has a11y_always; then
        echo "[org/gnome/desktop/a11y]" >> "$tmp"
        printf "always-show-universal-access-status=%s\n\n" "$(state_get a11y_always)" >> "$tmp"
    fi

    # Sound
    if state_has sound_theme || state_has event_sounds || state_has feedback_sounds || state_has over_amplification; then
        echo "[org/gnome/desktop/sound]" >> "$tmp"
        state_has sound_theme        && printf "theme-name=%s\n" "$(dconf_string "$(state_get sound_theme)")" >> "$tmp"
        state_has event_sounds       && printf "event-sounds=%s\n" "$(state_get event_sounds)" >> "$tmp"
        state_has feedback_sounds    && printf "input-feedback-sounds=%s\n" "$(state_get feedback_sounds)" >> "$tmp"
        state_has over_amplification && printf "allow-volume-above-100-percent=%s\n" "$(state_get over_amplification)" >> "$tmp"
        echo >> "$tmp"
    fi

    # Mouse
    if state_has mouse_accel || state_has mouse_natural || state_has mouse_speed; then
        echo "[org/gnome/desktop/peripherals/mouse]" >> "$tmp"
        state_has mouse_accel   && printf "accel-profile=%s\n" "$(dconf_string "$(state_get mouse_accel)")" >> "$tmp"
        state_has mouse_natural && printf "natural-scroll=%s\n" "$(state_get mouse_natural)" >> "$tmp"
        state_has mouse_speed   && printf "speed=%s\n" "$(state_get mouse_speed)" >> "$tmp"
        echo >> "$tmp"
    fi

    # Touchpad
    if state_has touchpad_send_events || state_has touchpad_speed || state_has touchpad_tap ||
       state_has touchpad_natural || state_has touchpad_twofinger || state_has touchpad_disable_typing; then
        echo "[org/gnome/desktop/peripherals/touchpad]" >> "$tmp"
        state_has touchpad_send_events    && printf "send-events=%s\n" "$(dconf_string "$(state_get touchpad_send_events)")" >> "$tmp"
        state_has touchpad_speed          && printf "speed=%s\n" "$(state_get touchpad_speed)" >> "$tmp"
        state_has touchpad_tap            && printf "tap-to-click=%s\n" "$(state_get touchpad_tap)" >> "$tmp"
        state_has touchpad_natural        && printf "natural-scroll=%s\n" "$(state_get touchpad_natural)" >> "$tmp"
        state_has touchpad_twofinger      && printf "two-finger-scrolling-enabled=%s\n" "$(state_get touchpad_twofinger)" >> "$tmp"
        state_has touchpad_disable_typing && printf "disable-while-typing=%s\n" "$(state_get touchpad_disable_typing)" >> "$tmp"
        echo >> "$tmp"
    fi

    # Power
    if state_has power_button || state_has auto_power_saver || state_has dim_screen ||
       state_has sleep_ac_type || state_has sleep_ac_timeout ||
       state_has sleep_battery_type || state_has sleep_battery_timeout; then
        echo "[org/gnome/settings-daemon/plugins/power]" >> "$tmp"
        state_has power_button          && printf "power-button-action=%s\n" "$(dconf_string "$(state_get power_button)")" >> "$tmp"
        state_has auto_power_saver      && printf "power-saver-profile-on-low-battery=%s\n" "$(state_get auto_power_saver)" >> "$tmp"
        state_has dim_screen            && printf "dim-screen=%s\n" "$(state_get dim_screen)" >> "$tmp"
        state_has sleep_ac_type         && printf "sleep-inactive-ac-type=%s\n" "$(dconf_string "$(state_get sleep_ac_type)")" >> "$tmp"
        state_has sleep_ac_timeout      && printf "sleep-inactive-ac-timeout=%s\n" "$(state_get sleep_ac_timeout)" >> "$tmp"
        state_has sleep_battery_type    && printf "sleep-inactive-battery-type=%s\n" "$(dconf_string "$(state_get sleep_battery_type)")" >> "$tmp"
        state_has sleep_battery_timeout && printf "sleep-inactive-battery-timeout=%s\n" "$(state_get sleep_battery_timeout)" >> "$tmp"
        echo >> "$tmp"
    fi

    # Session / blank screen
    if state_has idle_delay; then
        echo "[org/gnome/desktop/session]" >> "$tmp"
        printf "idle-delay=%s\n\n" "$(state_get idle_delay)" >> "$tmp"
    fi

    # Night Light
    if state_has night_enabled || state_has night_temp || state_has night_auto ||
       state_has night_from || state_has night_to; then
        echo "[org/gnome/settings-daemon/plugins/color]" >> "$tmp"
        state_has night_enabled && printf "night-light-enabled=%s\n" "$(state_get night_enabled)" >> "$tmp"
        state_has night_temp    && printf "night-light-temperature=uint32 %s\n" "$(state_get night_temp)" >> "$tmp"
        state_has night_auto    && printf "night-light-schedule-automatic=%s\n" "$(state_get night_auto)" >> "$tmp"
        state_has night_from    && printf "night-light-schedule-from=%s\n" "$(state_get night_from)" >> "$tmp"
        state_has night_to      && printf "night-light-schedule-to=%s\n" "$(state_get night_to)" >> "$tmp"
        echo >> "$tmp"
    fi

    # Login screen
    if state_has logo_enabled || state_has banner_enabled || state_has banner_text ||
       state_has disable_restart || state_has disable_user_list || state_has fingerprint; then
        echo "[org/gnome/login-screen]" >> "$tmp"

        if state_has logo_enabled; then
            if [[ "$(state_get logo_enabled)" == "true" ]]; then
                local logo_file
                logo_file="$(find "$APP_DIR" -maxdepth 1 -type f \
                    \( -name 'logo.jpg' -o -name 'logo.png' -o -name 'logo.webp' \) \
                    -print 2>/dev/null | head -n1)"
                if [[ -n "$logo_file" && -f "$logo_file" ]]; then
                    printf "logo=%s\n" "$(dconf_string "$logo_file")" >> "$tmp"
                else
                    printf "logo=''\n" >> "$tmp"
                fi
            else
                printf "logo=''\n" >> "$tmp"
            fi
        fi

        state_has banner_enabled  && printf "banner-message-enable=%s\n" "$(state_get banner_enabled)" >> "$tmp"
        state_has banner_text     && printf "banner-message-text=%s\n" "$(dconf_string "$(state_get banner_text)")" >> "$tmp"
        state_has disable_restart && printf "disable-restart-buttons=%s\n" "$(state_get disable_restart)" >> "$tmp"
        state_has disable_user_list && printf "disable-user-list=%s\n" "$(state_get disable_user_list)" >> "$tmp"
        state_has fingerprint     && printf "enable-fingerprint-authentication=%s\n" "$(state_get fingerprint)" >> "$tmp"
        echo >> "$tmp"
    fi

    if [[ -s "$tmp" ]]; then
        install -m 0644 "$tmp" "$DCONF_FILE"
    else
        rm -f "$DCONF_FILE"
    fi
    rm -f "$tmp"

    dconf update
}

# ------------------------------------------------------------
# GResource / CSS generation
# ------------------------------------------------------------

current_resource() {
    readlink -f "$GDM_LINK" 2>/dev/null || true
}

best_resource() {
    update-alternatives --query "$ALT_NAME" 2>/dev/null |
        sed -n 's/^Best: //p' |
        head -n1
}

choose_base_resource() {
    if [[ -f "$YARU_RESOURCE" ]]; then
        echo "$YARU_RESOURCE"
        return
    fi

    if [[ -f "$SHELL_RESOURCE" && "$SHELL_RESOURCE" != "$CUSTOM_RESOURCE" ]]; then
        echo "$SHELL_RESOURCE"
        return
    fi

    local best
    best="$(best_resource)"
    if [[ -n "$best" && -f "$best" && "$best" != "$CUSTOM_RESOURCE" ]]; then
        echo "$best"
        return
    fi

    local current
    current="$(current_resource)"
    if [[ -n "$current" && -f "$current" && "$current" != "$CUSTOM_RESOURCE" ]]; then
        echo "$current"
        return
    fi

    die "Could not locate a stock GDM theme resource."
}

save_previous_theme() {
    ensure_dirs

    if [[ ! -f "$PREVIOUS_THEME" ]]; then
        local current
        current="$(current_resource)"
        if [[ -n "$current" && "$current" != "$CUSTOM_RESOURCE" ]]; then
            printf '%s\n' "$current" > "$PREVIOUS_THEME"
            chmod 0644 "$PREVIOUS_THEME"
        fi
    fi
}

extract_resource() {
    local source="$1"
    local dest="$2"
    local resource relative output

    mkdir -p "$dest"

    while IFS= read -r resource; do
        [[ -n "$resource" ]] || continue
        case "$resource" in
            /org/gnome/shell/theme/*)
                relative="${resource#/org/gnome/shell/theme/}"
                ;;
            *)
                continue
                ;;
        esac

        output="${dest}/${relative}"
        mkdir -p "$(dirname "$output")"
        gresource extract "$source" "$resource" > "$output"
    done < <(gresource list "$source")
}

merge_shell_theme() {
    local configured source file rel target

    state_has shell_theme_dir || return 0
    configured="$(state_get shell_theme_dir)"

    if [[ -d "$configured/gnome-shell" ]]; then
        source="$configured/gnome-shell"
    else
        source="$configured"
    fi

    [[ -d "$source" ]] || return 0

    while IFS= read -r -d '' file; do
        rel="${file#"$source"/}"
        target="$1/$rel"
        mkdir -p "$(dirname "$target")"

        if [[ "$file" == *.css && -f "$target" ]]; then
            {
                echo
                echo "/* GDM Customizer shell theme */"
                cat "$file"
            } >> "$target"
        else
            cp -f "$file" "$target"
        fi
    done < <(find "$source" -type f -print0)
}

resource_customizations_present() {
    state_has background_type ||
    state_has shell_theme_dir ||
    state_has top_disable_arrows ||
    state_has top_disable_corners ||
    state_has top_text_color ||
    state_has top_background_color ||
    state_has banner_large
}

build_custom_css() {
    local css=""

    if state_has background_type; then
        case "$(state_get background_type)" in
            image)
                css+=$'\n.login-dialog { background: transparent; }\n'
                css+="#lockDialogGroup {"$'\n'
                css+=" background-image: url('resource:///org/gnome/shell/theme/gdm-customizer-background');"$'\n'
                if [[ "$(state_get_or background_adjust zoom)" == "repeat" ]]; then
                    css+=" background-position: 0 0;"$'\n'
                    css+=" background-size: contain;"$'\n'
                    css+=" background-repeat: repeat;"$'\n'
                else
                    css+=" background-position: center;"$'\n'
                    css+=" background-size: cover;"$'\n'
                    css+=" background-repeat: no-repeat;"$'\n'
                fi
                css+="}"$'\n'
                ;;
            color)
                css+=$'\n.login-dialog { background: transparent; }\n'
                css+="#lockDialogGroup { background-color: $(state_get background_color); }"$'\n'
                ;;
        esac
    fi

    local panel="#panel, #panel.login-screen, #panel.unlock-screen"
    local arrows="#panel .popup-menu-arrow, #panel.login-screen .popup-menu-arrow, #panel.unlock-screen .popup-menu-arrow"
    local corners="#panel .panel-corner, #panel.login-screen .panel-corner, #panel.unlock-screen .panel-corner"
    local buttons="#panel .panel-button, #panel.login-screen .panel-button, #panel.unlock-screen .panel-button, #panel .panel-button.clock-display, #panel.login-screen .panel-button.clock-display, #panel.unlock-screen .panel-button.clock-display"

    if [[ "$(state_get_or top_disable_arrows false)" == "true" ]]; then
        css+=$'\n'"${arrows} { width: 0px; }"$'\n'
    fi

    if [[ "$(state_get_or top_disable_corners false)" == "true" ]]; then
        css+=$'\n'"${corners} { -panel-corner-opacity: 0; }"$'\n'
    fi

    if state_has top_text_color; then
        css+=$'\n'"${buttons} { color: $(state_get top_text_color); }"$'\n'
    fi

    if state_has top_background_color; then
        css+=$'\n'"${panel} { background-color: $(state_get top_background_color); }"$'\n'
        if [[ "$(state_get_or top_disable_corners false)" != "true" ]]; then
            css+="${corners} {"$'\n'
            css+=" -panel-corner-opacity: 1;"$'\n'
            css+=" -panel-corner-background-color: $(state_get top_background_color);"$'\n'
            css+="}"$'\n'
        fi
    fi

    if [[ "$(state_get_or banner_large false)" == "true" ]]; then
        css+=$'\n.login-dialog-banner {\n font-size: 1.5em;\n font-weight: bold;\n}\n'
    fi

    printf '%s' "$css"
}

build_resource_xml() {
    local theme_dir="$1"
    local xml="$2"

    {
        echo '<?xml version="1.0" encoding="UTF-8"?>'
        echo '<gresources>'
        echo '  <gresource prefix="/org/gnome/shell/theme">'

        (
            cd "$theme_dir"
            while IFS= read -r -d '' item; do
                item="${item#./}"
                local escaped="$item"
                escaped="${escaped//&/&amp;}"
                escaped="${escaped//</&lt;}"
                escaped="${escaped//>/&gt;}"
                printf '    <file>%s</file>\n' "$escaped"
            done < <(find . -type f -print0 | sort -z)
        )

        echo '  </gresource>'
        echo '</gresources>'
    } > "$xml"
}

append_css_to_theme() {
    local theme_dir="$1"
    local css="$2"
    local file

    for file in gdm.css gnome-shell.css gnome-shell-dark.css gnome-shell-light.css gnome-shell-high-contrast.css; do
        if [[ -f "$theme_dir/$file" ]]; then
            {
                echo
                echo "/* BEGIN GDM CUSTOMIZER */"
                printf '%s\n' "$css"
                echo "/* END GDM CUSTOMIZER */"
            } >> "$theme_dir/$file"
        fi
    done
}

restore_resource() {
    local target=""

    if [[ "$(current_resource)" == "$CUSTOM_RESOURCE" ]]; then
        if [[ -f "$PREVIOUS_THEME" ]]; then
            target="$(cat "$PREVIOUS_THEME")"
        fi

        if [[ -z "$target" || ! -f "$target" || "$target" == "$CUSTOM_RESOURCE" ]]; then
            if [[ -f "$YARU_RESOURCE" ]]; then
                target="$YARU_RESOURCE"
            else
                target="$(best_resource)"
            fi
        fi

        [[ -n "$target" && -f "$target" && "$target" != "$CUSTOM_RESOURCE" ]] ||
            die "Could not find a safe theme resource to restore."

        update-alternatives --set "$ALT_NAME" "$target"
    fi

    if update-alternatives --query "$ALT_NAME" 2>/dev/null |
       grep -Fq "Alternative: $CUSTOM_RESOURCE"; then
        update-alternatives --remove "$ALT_NAME" "$CUSTOM_RESOURCE" || true
    fi

    rm -f "$CUSTOM_RESOURCE"
}

apply_resource_state() {
    ensure_dirs

    if ! resource_customizations_present; then
        restore_resource
        return
    fi

    save_previous_theme

    local base work theme_dir xml compiled css bg
    base="$(choose_base_resource)"
    work="$(mktemp -d /tmp/gdm-customizer.XXXXXX)"
    theme_dir="$work/theme"
    xml="$work/gnome-shell-theme.gresource.xml"
    compiled="$work/gnome-shell-theme.gresource"

    extract_resource "$base" "$theme_dir"
    merge_shell_theme "$theme_dir"

    if [[ "$(state_get_or background_type none)" == "image" ]]; then
        bg="$(state_get_or background_image "")"
        [[ -f "$bg" ]] || {
            rm -rf "$work"
            die "Configured background image no longer exists."
        }
        install -m 0644 "$bg" "$theme_dir/gdm-customizer-background"
    fi

    css="$(build_custom_css)"
    append_css_to_theme "$theme_dir" "$css"

    build_resource_xml "$theme_dir" "$xml"

    if ! glib-compile-resources \
        --sourcedir="$theme_dir" \
        --target="$compiled" \
        "$xml"; then
        rm -rf "$work"
        die "Failed to compile the GDM theme. The active theme was not changed."
    fi

    if ! gresource list "$compiled" >/dev/null 2>&1; then
        rm -rf "$work"
        die "The compiled GResource failed validation. The active theme was not changed."
    fi

    install -m 0644 "$compiled" "$CUSTOM_RESOURCE"

    update-alternatives --install \
        "$GDM_LINK" \
        "$ALT_NAME" \
        "$CUSTOM_RESOURCE" \
        5

    update-alternatives --set "$ALT_NAME" "$CUSTOM_RESOURCE"

    rm -rf "$work"

    [[ "$(current_resource)" == "$CUSTOM_RESOURCE" ]] ||
        die "The custom resource was created but did not become active."
}

time_to_decimal() {
    local value="$1"
    if [[ "$value" =~ ^([0-9]{1,2}):([0-9]{2})$ ]]; then
        local h="${BASH_REMATCH[1]}"
        local m="${BASH_REMATCH[2]}"
        if (( h >= 0 && h <= 23 && m >= 0 && m <= 59 )); then
            awk -v h="$h" -v m="$m" 'BEGIN { printf "%.6f\n", h + m/60 }'
            return 0
        fi
    fi
    return 1
}

apply_current_display() {
    local user_home source
    user_home="$(calling_user_home)"
    source="${user_home}/.config/monitors.xml"

    if [[ ! -s "$source" ]]; then
        echo
        echo "No usable monitors.xml was found at:"
        echo "  $source"
        pause
        return
    fi

    ensure_dirs

    if [[ ! -f "$PREVIOUS_MONITORS" && ! -f "$MONITORS_MARKER" ]]; then
        if [[ -f /etc/xdg/monitors.xml ]]; then
            cp -a /etc/xdg/monitors.xml "$PREVIOUS_MONITORS"
        else
            touch "$MONITORS_MARKER"
        fi
    fi

    install -Dm644 "$source" /etc/xdg/monitors.xml

    machinectl shell "${GDM_USER}@" /usr/bin/env \
        DCONF_PROFILE=gdm \
        gsettings set org.gnome.mutter experimental-features \
        "['scale-monitor-framebuffer']" >/dev/null 2>&1 || true

    echo
    echo "Current desktop display configuration copied to GDM."
    echo "Installed as /etc/xdg/monitors.xml"
    pause
}

restore_display() {
    if [[ -f "$PREVIOUS_MONITORS" ]]; then
        install -Dm644 "$PREVIOUS_MONITORS" /etc/xdg/monitors.xml
        rm -f "$PREVIOUS_MONITORS"
    elif [[ -f "$MONITORS_MARKER" ]]; then
        rm -f /etc/xdg/monitors.xml
        rm -f "$MONITORS_MARKER"
    else
        echo
        echo "GDM Customizer has no saved display configuration to restore."
        pause
        return
    fi

    echo
    echo "Display configuration restored."
    pause
}

    echo "================================================"
    echo "            Restore Customizations"
    echo "================================================"
    echo
    echo "This removes ONLY changes owned by GDM Customizer:"
    echo
    echo "  - its custom GResource alternative"
    echo "  - its 99-gdm-customizer dconf file"
    echo "  - its saved logo/wallpaper/theme state"
    echo "  - its display file only if this tool installed it"
    echo
    echo "Other GDM configuration files are left alone."
    echo
    read -r -p "Continue? [y/N]: " answer

    case "$answer" in
        y|Y|yes|YES) ;;
        *) return ;;
    esac

    restore_resource

    rm -f "$DCONF_FILE"
    dconf update

    if [[ -f "$PREVIOUS_MONITORS" ]]; then
        install -Dm644 "$PREVIOUS_MONITORS" /etc/xdg/monitors.xml
    elif [[ -f "$MONITORS_MARKER" ]]; then
        rm -f /etc/xdg/monitors.xml
    fi

    rm -rf "$STATE_DIR"
    rm -f \
        "$PREVIOUS_THEME" \
        "$PREVIOUS_MONITORS" \
        "$MONITORS_MARKER" \
        "${APP_DIR}/logo.jpg" "${APP_DIR}/logo.png" "${APP_DIR}/logo.webp" \
        "${APP_DIR}/wallpaper.jpg" "${APP_DIR}/wallpaper.png" "${APP_DIR}/wallpaper.webp" \
        "$CUSTOM_RESOURCE"

    rmdir "$APP_DIR" 2>/dev/null || true

    echo
    echo "GDM Customizer settings restored."
    echo "Log out or reboot to see all changes."
    pause
}
